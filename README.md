# DabangSearcher

다방(dabangapp) 부평권 월세 매물을 자동 수집해서 **고정 주소 한 장**으로 보여주는 페이지.

- 공개 주소: https://9503chl.github.io/DabangSearcher/
- 주소는 고정. 갱신할 때마다 `index.html` 만 덮어쓰니까 링크는 계속 살아있음.

## 구성

- `index.html` — 페이지 본체. 레이아웃/CSS/렌더링 스크립트 전부 인라인이라 파일 하나로 오프라인에서도 열림(카톡 전송용).
  매물 데이터는 `<!-- DATA:START -->` ~ `<!-- DATA:END -->` 사이 `window.DABANG` 블록에만 들어감. 갱신은 이 블록만 교체.
- `data/seen.json` — 이미 상세까지 확인한 매물 원장. `accepted`(주거용 채택) / `excluded`(근생·숙박·업무 등 탈락).
  재클릭 방지 + `[NEW]` 판정에 씀. 매 실행마다 누적.

## 수집 조건

월세 · 보증금 200~2000만 · 월세 60만 이하 · 단기 제외 ·
**건축물용도가 공동주택/단독주택인 것만**(리스트에 '원룸'이어도 상세페이지 용도로 판정) ·
정렬은 보증금 내림차순(같으면 사용승인일 최신순).

역: 1호선 부평·백운·동암·주안 / 7호선 석남·산곡·부평구청·굴포천 / 인천1호선 인천시청·간석오거리·부평삼거리·동수.

## 갱신

Claude Code 스케줄 태스크 `dabang-bupyeong-monthly` 가 돌면서
다방 내부 API로 수집 → `index.html` 데이터 블록 교체 → 커밋/푸시 → GitHub Pages 반영.
로그인된 Chrome 세션이 필요해서 로컬에서만 동작한다.
